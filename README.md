# Telecom Sector Data Analytics Engineer Internship

## Project Overview
This project focuses on analysing challenges in the telecommunications industry using data analytics and Python.

## Objectives
- Understand customer churn and retention.
- Explore network performance and service quality.
- Identify important business questions.
- Define hypotheses and key performance indicators (KPIs).
- Explore suitable data analytics techniques.

## Business Questions
1. What factors may influence customer churn?
2. Which locations experience poor network performance?
3. Does faster complaint resolution improve customer satisfaction?
4. How can data analytics improve telecom operational efficiency?

## Potential Data Sources
- Kaggle: Customer churn datasets.
- Ookla Open Data: Network performance data.
- International Telecommunication Union (ITU): Telecom industry statistics.

## Tools and Technologies

- Pandas
- Matplotlib
- Jupyter Notebook
- Microsoft Word
- GitHub
